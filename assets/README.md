# Zdrojové ikony pro Android / Capacitor

Až bude přidán Capacitor Android projekt, najdeš zde zdrojové PNG ikony ve velikosti 1024 × 1024 px. Všechny tři soubory nyní používají stejný obrázek jako `icon-only.png`, aby vzhled značky zůstal shodný:

- `icon-only.png` – celá ikona pro obchod a systémy, které nepoužívají adaptivní ikony.
- `icon-foreground.png` – průhledná přední vrstva adaptivní ikony.
- `icon-background.png` – pozadí adaptivní ikony.

Z těchto zdrojů pak Capacitor Assets vygeneruje Androidové varianty do nativního projektu.
